# Анализ пользовательской активности и результатов A/B-тестирования контентной платформы (Яндекс Книги)

## 🛠 Стек технологий и инструменты
* **Языки и библиотеки:** Python (Pandas, SciPy, Statsmodels)
* **Базы данных:** SQL (сложные запросы, агрегации, JOIN)
* **Среда разработки:** Jupyter Notebook

---

## 📊 1. Описание проекта и бизнес-задача
Цель проекта — исследовать метрики пользовательской вовлеченности контентного сервиса в разрезе регионов, выявить поведенческие аномалии, а также провести математическую оценку результатов A/B-тестирования при внедрении нового интерфейса платформы.

**Основные задачи:**
1. Написать SQL-запросы для выгрузки логов активности пользователей двух крупнейших мегаполисов.
2. Провести когортный и продуктовый анализ пользовательских сессий, локализовать аномалии.
3. Проверить статистическую значимость различий в активности пользователей Москвы и Санкт-Петербурга.
4. Проанализировать результаты A/B-теста, сопоставить математический эффект с бизнес-требованиями ТЗ и выдать рекомендацию по раскатке нового интерфейса.

---

## ⚙️ 2. Ход работы и технические решения

### Шаг 1: Выгрузка данных и когортный анализ сессий
* Написал SQL-запросы с использованием многоуровневых конструкций `JOIN` и агрегатных функций для извлечения сырых логов активности.
* Рассчитал метрики вовлеченности сессий. Обнаружил экстремальные поведенческие выбросы: группа «супер-пользователей» искажала среднее время активности до 11 часов, в то время как реальная медиана составляла менее 1 часа. Аномалии были локализованы и сегментированы.

### Шаг 2: Проверка продуктовых гипотез
* Из-за сильного дисбаланса выборок (73% пользователей из Москвы против 27% из Санкт-Петербурга) применил **t-тест Уэлча** для сравнения средних показателей.
* Доказал, что различия в среднем времени активности между жителями двух столиц статистически не значимы (p-value = 0.34).

### Шаг 3: Статистический анализ A/B-теста
* Для оценки изменения конверсии в целевое действие между контрольной группой A и тестовой группой B применил односторонний **Z-тест пропорций** (библиотека `statsmodels`).
* Зафиксировал статистически значимый рост целевой метрики в группе B до **31.17%** по сравнению с **28.98%** в группе A (p-value = 0.0085).

## 📈 3. Ключевые результаты и бизнес-выводы

1. **Несоответствие плановым KPI:** На основе результатов Z-теста подсветил продуктовой команде важный бизнес-ньюанс: плановый прирост конверсии в 3 процентных пункта (п.п.), заложенный в техническом задании, не был достигнут. Фактический прирост составил **2.19 п.п.**
2. **Итоговое продуктовое решение:** Несмотря на недостижение целевого KPI из ТЗ, выдал обоснованную рекомендацию внедрять новый интерфейс. Математический анализ подтвердил чистый, стабильный и статистически значимый рост конверсии без негативного влияния на сопутствующие продуктовые метрики, что гарантирует бизнесу дополнительный объем целевых действий.
