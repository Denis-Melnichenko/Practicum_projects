# Проектная деятельность в анализе данных

В данном репозитории собраны ключевые аналитические проекты, выполненные в рамках решения комплексных продуктовых и коммерческих задач. Каждый кейс прошел полный цикл от ad hoc выгрузок сырых данных и предобработки до проверки статистических гипотез и автоматизации бизнес-отчетности.

## 🚀 Навигация по проектам

* ### [📊 Комплексный продуктовый анализ развлекательного сервиса](./entertainment_service_analytics)
  Исследование ключевых бизнес-показателей (выручка, заказы, вовлеченность), выявление скрытых географических рисков и структуры продаж, фрод-мониторинг бот-активности и автоматизация отчетности в **Yandex DataLens**.
  * **Стек:** Python (Pandas, Matplotlib, Seaborn, SciPy), SQL, Yandex DataLens.

* ### [📚 Анализ пользовательской активности и результатов A/B-тестирования](./content_service_ab_testing)
  Выгрузка логов активности пользователей двух столиц, проведение когортного анализа сессий, проверка продуктовых гипотез с помощью t-теста Уэлча и оценка бизнес-эффективности интерфейсных изменений через Z-тест пропорций.
  * **Стек:** Python (Pandas, SciPy, Statsmodels, Matplotlib), SQL.
